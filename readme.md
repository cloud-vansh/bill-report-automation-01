# Bill Report Automation

A Streamlit web application for automated bill report processing and management.

## Features
- 📊 Process multiple Excel files (Bill Report, Job Report, E-Invoice)
- 🔄 Intelligent bill number merging
- 📅 Month-wise report generation
- 💾 Export to Excel and CSV formats

## How to Use
1. Upload your three Excel files (Bill Report, Job Report, E-Invoice Report)
2. Select the month you want to process
3. Choose update mode (Overwrite or Append)
4. Click "Process Report"
5. Download the generated report

## File Requirements
- All files must be in .xlsx format
- Files must contain specific column headers (JOB NO, JOB DATE, etc.)
